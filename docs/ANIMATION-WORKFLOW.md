# 从原画到可用的 AR 动画：你该在哪里做什么

## 先定产物，避免白花生成次数

本轮先完成原画静态悬浮卡：它是有厚度、在空间里定位的卡片，画面本身不动。手机移动形成视差。下一轮才做动作资产。

**我们的真正 3D 交付格式选 GLB（模型、材质、骨骼/形变、动作一起打包）。MidJourney 和 Linkfox 先负责动作样片，不把 MP4 当成 GLB。** 视频可以贴到空间平面上，但不能因此从侧面看见角色真实侧面。

| 你想判断什么 | 去哪里 | 带回什么 | 我接手什么 |
| --- | --- | --- | --- |
| 动作、情绪、节奏是否对 | 优先用已付费 Linkfox；MJ 作备选 | 原始视频＋起始图＋提示词 | 审动作，不直接当三维交付 |
| 角色/道具侧面、背面长什么样 | 已批准设定图；必要时 Meshy 做初模 | 多视图＋未压缩模型 | 检查品牌一致性、拓扑、材质 |
| 精确到关节、秒数、起止姿态的 3D 动作 | Blender；复杂角色由动画师操作 | `.blend` 源文件＋带动作的 `.glb` | 检查导出并接入 AR，不让你写追踪代码 |

当前没有理由先让你购买新订阅。先用现有工具定一个短动作，再决定初模工具或动画师投入。

## A. 用 Linkfox 做第一条动作样片

进入 [Linkfox](https://www.linkfox.com/) → **AI视频 → 图转视频 → 首尾帧**，用自定义描述。上传批准的单一角色图，不上传整张品鉴卡让模型改字；设置 5 秒、720p、无声音，关闭自动提示词优化以保留工单约束。先生成一条，查看结果后下载原视频。不同模型的时长/参数以界面为准。操作入口依据[官方图转视频说明](https://wiki.linkfox.com/assets/image-to-video-source-full/document.html)。

第一条建议只验证“朏朏注意到观众，轻点头，回到原姿态”。不同时做跳跃、绕瓶、变装、持物切换或运镜。提示词如下；输入图若已拿着酒管，就保持酒管和双手静止。

> 使用上传图中的同一个朏朏，保留原有头饰、异色眼睛、毛色、纹样、身体比例及已有持物，不设计新角色。固定镜头，完整角色始终在画面内，背景和光照不变。0–1秒保持原姿态；1–2.5秒头部轻轻下点一次；2.5–4秒抬头回到起始姿态；4–5秒静止。身体、双手和持物保持原位。无镜头推拉、环绕、切镜、字幕、额外肢体、物体融化或变形。动作幅度小、自然、友好。

这份秒表是意图约束，不是视频模型的逐帧保证。失败时一次只改“动作幅度”“头部速度”或“身份稳定性”中的一项；同一问题连续两次仍错，就停止烧生成次数，将已认可的关键姿态交给三维动画步骤。

## B. 如果你选 MidJourney

进入 [MidJourney Create](https://www.midjourney.com/imagine) → 上传批准图 → 放入 **Animate / Starting Frame** → 手动填写动作描述；用 **Low Motion、Raw、Batch 1**。先用 SD 审动作，通过再出 HD。需要首尾衔接时使用 Loop/Ending Frame；下载 **Raw Video**，不要 GIF。当前视频输出为 MP4，按钮和参数依据[官方 Video 文档](https://docs.midjourney.com/hc/en-us/articles/37460773864589-Video)。

可用同一动作的英文描述：

> Locked camera, one continuous shot. Keep the exact same mascot, headdress, eye colors, markings, proportions and held object as the input. Hold the initial pose, make one small friendly head nod, return to the exact starting pose and hold. The body, hands and prop stay still. No camera motion, cuts, new text, extra limbs, costume changes or morphing. --motion low --raw --bs 1

MJ/Linkfox 二选一即可，别为同一动作同时开两个制作流程。这里获得的是动作参考，不是可接入 AR 的三维角色。

## C. 真正 3D：模型先过关，再做动画

本地 `2品牌宣传/2品牌册子与长期美术资产/03品牌IP朏朏/` 可读；已查看一张成品角色图，另有线稿、手绘 PNG/PSD、不同头饰版本。当前未在该目录的展开文件中找到 `.glb/.fbx/.blend`，尚未检查压缩包内容，因此不能断言完全没有模型。文件名不能决定哪一款是本次批准 IP。

1. **先选定一个朏朏版本。** 我整理候选并让你确认身份；不能混用不同头饰、异色瞳或持物设计。缺少侧背面时，先补齐/批准设定，不能把模型猜测当品牌事实。
2. 若没有现成模型，可在 [Meshy](https://www.meshy.ai/) → 3D Model → Image to 3D 做初模：上传同一角色的正/侧/背图，先选面向实时用途的 Smart Topology，关闭 Image Enhancement，保留批准图的细节；查看生成模型的各个角度，不直接点“完成”。只有轮廓、比例、纹样和持物都过关才进入绑定。[图生3D官方操作说明](https://docs.meshy.ai/en/webapp/image-to-3d) Meshy 的 Animate 支持自动绑定及预设动作、可导出 GLB/FBX；非标准体型与精确表情不应依赖自动绑定保证。[官方能力边界](https://docs.meshy.ai/en/webapp/guides/animate)
3. **动作定稿用 Blender。** 导入模型；身体、头、手、持物分清归属；绑定骨骼和必要形变；持物跟随对应骨骼而不是各自漂浮。角色若自动绑定失败或有穿模，让三维制作人员处理，不让你盲调骨骼参数。
4. 在 Blender 的 Dope Sheet → Action Editor 为一个动作建独立 Action，按下面工单设关键帧。在 Graph Editor 调缓入缓出。约束/模拟应烘焙成可导出的动作；不要只交 Blender 视窗里能动、导出后不动的文件。
5. File → Export → glTF 2.0，选 **glTF Binary (.glb)**、所需对象及动画。先导出一个动作验证，再扩展动作库。标准 glTF 可承载对象变换、骨骼和形变动画，不等于所有 Blender 材质/模拟都直接支持。[Blender glTF 官方说明](https://docs.blender.org/manual/en/3.6/addons/import_export/scene_gltf2.html) 文档版本为3.6；实际导出界面以制作人员使用的版本为准，导出后重新导入的验收不能省略。

## D. 给制作人员的第一张精细动作工单

下面是**三维制作起始建议，不是已批准的角色表演**。视频样片负责确认感觉，这张表负责可重复执行。

| 项目 | 定义 |
| --- | --- |
| 资产身份 | 一个已批准朏朏版本；头饰、纹样、瞳色、比例不变 |
| 空间 | 原点在两脚中点的地面；GLB 使用米；AR 展示高度由我在代码中设，不让动画师按手机像素做 |
| 动作名 | `greet_nod`，5秒；另交 `idle`，约4秒循环 |
| 根节点 | 位置、朝向不动；不烘焙摄影机运动，不绕实物画轨道 |
| 0–1秒 | 起始姿态保持 |
| 1–2.5秒 | 头部下点约8°，缓入缓出；头饰随头，身体稳定 |
| 2.5–4秒 | 回到起始角度，不突然弹回 |
| 4–5秒 | 保持；首尾姿态一致，速度接近零 |
| 持物 | 原持物位置与抓握关系不变；不自动换手、不插入胸口 |
| 暂不做 | 口型、对白、毛发模拟、跳跃、绕瓶跑、捡取酒管 |
| 交付 | GLB＋Blender源文件＋预览MP4＋贴图及许可说明；动作有明确名称 |
| 首轮性能预算 | 单角色先以≤30k三角面、≤4材质、贴图≤2048、GLB≤5MB为目标；这是移动端项目预算，不是引擎硬上限 |

我来验收：重新导入导出的 GLB，检查动作是否真的存在、开头/结尾/循环、背面与关节、纹理、透明边、脚底原点、尺寸、手机帧率及与试管的遮挡。你验收：是不是这只朏朏、动作气质与幅度是否对。两者都通过才接入消费者入口。

**你现在不用去生成一整场 AR。** 先看这轮静态卡；要进入角色阶段时，只需确认一个朏朏版本和一个短动作。我负责把它收敛成以上工单并检查交付，不把模型、动作、追踪和部署混成一句大提示词。
