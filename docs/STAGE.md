# 当前 AR 空间规格：竖直试管

现有试管竖直、二维码领带附于上部。现场照片就是使用场景。旧横放品鉴卡布局已停用。

| 项目 | 当前约束 |
| --- | --- |
| 入口 | 既有二维码 → /ar/；真实相机全屏，8th Wall / XR8 |
| 原点 | 领带识别矩形中心；局部+X向右、+Y向上、+Z离开标签正面 |
| 内容容器 | 米制局部坐标固定(0,0,0.015)，不随视口缩放 |
| 角色 | 原画高80mm，宽由实际PNG比例决定 |
| 曲面 | 共享接缝、动态法线；总深度≤3mm，含呼吸极值 |
| 内部位置 | 底边y=-40mm、内部前移3mm；容器15mm并非所有表面像素的最终深度 |
| 透明度 | 普通Alpha=0.75，不用加色洗白原画 |
| 节奏 | 五张每1000ms硬切，无背景卡、横向站位或新增遮挡圆柱 |
| 实体 | 不改二维码、吊牌、打印；最后再确定纸模和精确位置 |

代码源：`site/ar/vertical-stage.js` 为原画毫米空间，`site/ar/app.js` 做米制装配；`xr8-anchor.js` 做目标尺度换算，不改动画尺寸迁就标记。

`tie-label` 裁自母版(45,2640)-(477,3150)。配置宽约36.576mm来自母版名义180mm宽，**不是用户实测值**。15mm和80mm也是当前名义尺度，不声称已完成毫米级实物标定。PNG像素数不能决定印刷尺寸。

## 连续观看

短暂图像丢失时，有效世界定位最多接续1500ms。无可靠世界定位则隐藏并暂停；短暂重新识别保留当前帧，超时重置。不通过增加厚度、改吊牌或强迫用户固定手机解决。

算法与生命周期可以本地检查；手机世界定位、角度、反光和距离必须以真机结果判断，未实测不写成通过。
