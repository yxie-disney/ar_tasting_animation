# V2 physical and runtime contract

## Objective and ownership

The objective is AR animation garnish around the physical tube. Card artwork varies per SKU and cannot own mandatory feature coverage. A standardized module on the camera side of the tube supplies the primary anchor. Keep the same module placement and circle offset across production cards. Existing branding and flavor content above the interaction area remain unchanged; the awards area is replaced.

## Frozen for this test, not production validated

- Preserve v1 SVG width 140 mm, height 310 mm, viewBox 1122 × 2480. Preserve v1 print settings; user printed on A4 and measured the ring at approximately 30 mm. This does not prove the physical card trim is 140 × 310 mm.
- Preserve ring center (561, 1688), radius 120.2143 source units, stroke 3.6064 source units.
- Module source bounding box: x=304.542857, y=1904, width=512.914286, height=384.685714.
- Nominal module: 64 × 48 mm. QR: 34 mm including its four-module quiet zone; version 5, error correction M, 37 × 37 data matrix. Long test URL is intentionally real; a future short URL requires regenerating/revalidating the complete target.
- Module center is 50.951872 nominal mm below the tube base. Use the checked-in geometry.json; never estimate this offset from a screenshot.
- The official processor receives a clockwise-rotated 960 × 1280 bitmap with isRotated=false. Its target width is 48 mm and height 64 mm. Target +X points toward the card's top; +Y points toward its left. Card-local content is rotated -90° around Z; +Z extends above the card.
- All newly added SVG text is outlined. The complete-card PNG remains 1683 × 3720, as in v1. Physical size is controlled by the SVG and the same user print scaling, not inferred from PNG DPI.

## Recognition and occlusion

Only the module is in the target. The rose and tasting illustrations may change or disappear. No claim is made that arbitrary partial occlusion remains trackable; that is a device test. From the intended QR-side view, the module lies in front of the upright tube. UI copy instructs that approach. A hand, shadow, or different approach can still cover it.

This P1 validates the full primary-anchor → tube-base transform → garnish slice. Tube placement is explicitly confirmed with a button, and the page says automatic tube detection is not connected. This accepts the user's other Ø29 mm tube for P1. Do not disguise manual confirmation as computer vision.

P2 must supply real, permissive tube presence evidence in the known card-local region. A cylindrical label tracker detects known printed texture; it does not recognize every similarly sized glass cylinder. Loosening application pose gates cannot make an unrecognized label produce events. If texture-based confirmation is retained, measure its actual user benefit and burden before making it required for launch.

No SLAM is used. Lost or stale planar pose hides the overlay; confirmation survives up to 1.2 seconds. Reacquisition must lock again. Holding the old camera-relative pose would make the garnish stick to the screen, so it is intentionally not rendered.

The nominal tube occluder relies on a tube centered and upright on the ring. If the user moves it after manual confirmation, P1 does not know; use reset/reposition. The long tube amplifies rotational error. Test alignment at the cap as well as the base.

## Evidence so far

- QR raster decodes back to the intended URL.
- Official target metadata and resources generated by @8thwall/image-target-cli 1.0.0.
- Browser scene preview renders; camera/engine initializes with no page errors.
- Synthetic camera input runs the actual engine, detects the standard module and reaches the real found/updated state. In a front-facing 1280 × 960 test, the projected base center is about 1.6 pixels from the known printed circle center.
- State tests cover explicit confirmation, short reacquisition, long loss, missing updates, and physical-scale conversion.

Synthetic tests do not validate physical print, grayscale toner, actual 45° phone viewing, WeChat compatibility, shadows, reflections, or millimeter stability. Do not describe this as a passed phone test.

## Next acceptance

2. From the QR side, lock with the upper card artwork hidden. Green outline and ring coincide with print.
3. Manual confirmation starts garnish along the physical tube, with the rear half hidden by the tube.
