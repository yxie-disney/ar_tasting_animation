# 五张朏朏：真实原像素切片

仓库存储切片PNG、蒙版和连续曲面控制数据；ZIP打包副本和ORA编辑工程保留原本地目录，不纳入Git。下文分离图层的深度值仅为历史对比，当前动画使用 `surface/` 中的连续3mm曲面。

先看 **all-five-layers.png**；每个角色目录里看 **layers-contact.png**。它们展示真正导出的独立图层，不是深度着色图。`index.html` 是本地检查页，包含图层开关、真实平面深度和侧看角度；不修改线上体验。

## 已交付

- 力士：地面投影、后方试管与莲饰、身体/双手/服饰，共3层。
- 妙音鸟：台座、翅膀、身体、前方酒管、双手，共5层。
- 岩画：台座、披风、身体/徽章、竖直酒管、握管手，共5层。
- 螭吻：地面、头饰、身体/披风、倾斜酒管、握管手，共5层。
- 角盔：地面、角盔、身体/披风、横斜酒管、双手，共5层。

合计23张透明切片PNG、23张黑白蒙版、5个OpenRaster `.ora` 分层文件（Krita/GIMP可编辑）。每层保持原图完整画布和像素坐标；导入Figma时按原尺寸对齐，不要逐层单独“裁到内容”。PNG全部来自已有原画，不生成、不补画、不改色。没有凭空另造宣纸背景。

## 文件怎么读

- `body.png` 等：真正的透明切片，供后续AR/排版使用。
- `*.mask.png`：该层拥有的原始可见像素；不是灰度深度图。
- `reassembled.png`：全部切片零偏移叠回的结果。五张可见RGBA像素差、alpha差均为0，见 `verification.json`。
- `cut-boundaries.png`：原图上用粉色标出实际切口。
- `body-missing-map.png`：身体可见部分＋前方物体占据区域的红色标记。红色是遮挡覆盖范围，不是推断出来的完整身体；其中某些区域本来就不是身体。
- `foreground-coverage.png`：上面的红色标记单独一层。力士道具在后方，因此此图为空，不能理解成后方道具没有遮挡缺失。
- `layers.json` / `manifest.json`：层名、原尺寸、原图哈希、深度试验值。
- `cuts.json`：可编辑的手工轮廓/复核修正。它们不是自动语义分割，不宣称发丝级精修。

## 深度坐标——现在是本地分层试验值，未发布

以角色身体平面为 **局部Z=0**；正值朝观看者。

| 图层 | 局部Z（场景毫米） |
|---|---:|
| 力士后方试管、妙音鸟翅膀 | -6 |
| 岩画披风 | -5 |
| 螭吻/角盔头饰 | -4 |
| 台座/地面画片 | -2 |
| 身体 | 0 |
| 前方试管 | +6 |
| 压在试管上的手 | +6.4 |

沿用原舞台时：角色基准纸面X=34.75，`纸面X=34.75-局部Z`。纸面+Z仍表示竖直向上，脚底纸面Z=35，角色总高80；不是把这两个不同坐标系的Z混用。背景卡保持纸面X=55。

本地预览的呼吸开关：周期2.4秒，所有非地面图层共用脚底支点做±1.2%竖向伸缩；手和道具一起跟随，不增加整体前后摆动。不等同于角色骨骼呼吸，也没有开启新流光、转场或粒子。此开关是明确标注的动态试验，默认关闭，未写入线上播放组件。

## 已知缺口，不伪装成可任意运动的完整部件

分割只能恢复画面上已有的像素。身体被试管挡住的区域、试管被手和耳朵挡住的区域、披风与翼根在身体后方的区域、底座在脚下的区域，原稿都没有画出来。

因此：**零偏移可以精确重叠合，不代表拉开深度、转到侧面后就无缺口。** 检查页允许侧看并展示这些缺口，不用整张原画垫在后面掩盖，也不自行生成补全。当前图层可作为后续修补/运动制作的真实基础，但不能冒称已完成可任意视角观看的AR角色。

复现：`python tools/extract-feifei-layers.py`。源PNG来自 `site/ar/assets/slides/feifei-1…5.png`；脚本不会修改源文件。检查页通过 `node tools/serve-feifei-layers.mjs` 启动，仅监听本机 `http://localhost:8121/`。
